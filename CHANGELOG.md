# Изменения Klutz

Версии — по semver: `MAJOR.MINOR.PATCH`. Номер один на всё приложение и
меняется в трёх местах сразу: `src-tauri/tauri.conf.json`,
`src-tauri/Cargo.toml`, `package.json`. Интерфейс (титулбар, «О программе»)
берёт его из сборки сам.

Встроенные части отслеживаются отдельно:

| Часть | Откуда | Где зафиксирована версия |
|---|---|---|
| zapret-discord-youtube | загружает пользователь (релиз Flowseal) | `LOCAL_VERSION` в `service.bat` релиза |
| TgWsProxy | встроен, собран из Flowseal/tg-ws-proxy | `BUNDLED_VERSION` в `src-tauri/src/tgws.rs` — менять вместе с пересборкой `bin/TgWsProxyHeadless.exe` |

«О программе → Проверить обновления» сверяет обе части с последними
версиями на GitHub.

## 1.0.0 — 2026-09-11

Первая версия на Tauri (раньше — Electron): установщик ~12 МБ вместо ~90.

Компоненты: zapret-discord-youtube (проверено с 1.9.9c), TgWsProxy 1.10.1.
У Flowseal уже вышел TgWsProxy 1.10.2 — войдёт в следующую версию Klutz.

- Подбор стратегии: тесты HTTP/Ping, DPI-checker и воронка DPI → HTTP
  (HTTP только по конфигам, прошедшим DPI на 100%).
- Фоновая проверка связи, самолечение (переключение на следующую стратегию
  из последнего прогона), периодический автопрогон тестов, когда никого нет.
- Telegram-прокси (TgWsProxy): запуск, настройки, ссылка tg://proxy.
- Трей со своим меню: статус и цели, переключение стратегии, тумблер
  Telegram.
- Служба Windows, автозапуск через Планировщик, уведомления со своим
  звуком, диагностика, обслуживание (ipset, hosts, кэш Discord), экспорт и
  импорт настроек, свои адреса для проверки.
